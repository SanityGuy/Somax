# Somax
Somax is a statically typed programming language built with Python as the first interpreter and will be shifting to C very soon. 

## Additional Information
This project was made by [SouyanDev](https://github.com/SanityGuy) to combine both Python's readable syntax with C/Java logic and handling.
</br>
Currently this project is progressing on development with a few samples

## Example Usage
Makesure you already installed Python 3 or higher and have clone this directory.
```command
python somax.py examples/hello.smx
```
